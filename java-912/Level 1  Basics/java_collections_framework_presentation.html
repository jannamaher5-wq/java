1. ما هو Java Collections Framework (JCF)؟

هو إطار عمل موحّد يوفر واجهات (Interfaces) وفئات (Classes) تتيح للمطورين تخزين وإدارة المجموعات من الكائنات بكفاءة، بدلاً من التعامل المباشر مع المصفوفات العادية (Arrays) ذات الحجم الثابت.

تسلسل Collection الأساسي

يبدأ من الواجهة Iterable ثم Collection والتي يتفرع منها ثلاث واجهات رئيسية: List و Set و Queue.

تسلسل Map المستقل

تعتبر الواجهة Map<K,V> شجرة مستقلة ولا ترث من Collection لأنها تعتمد على تخزين الأزواج (Key-Value) وليس العناصر المنفردة.

لماذا نستخدم Collections بدلاً من المصفوفات العادية (Arrays)؟

  • الحجم الديناميكي: تتمدد وتتقلص المجموعات تلقائياً في الذاكرة.
  • خوارزميات جاهزة: توفر خوارزميات للفرز (Sorting)، البحث (Searching)، والتقليب (Shuffling).
  • الأمان والكفاءة: توفر دعم البرمجة المعممة (Generics) والأمان ضد أخطاء الذاكرة.

2. واجهة القوائم (List Interface)

تسمح بتخزين عناصر مكررة وتحافظ على ترتيب الإدخال (Insertion Order) ويمكن الوصول للعناصر بالـ Index: 

import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;

public class ListDemo {
    public static void main(String[] args) {
        // ArrayList: مصفوفة ديناميكية متصلة (سريعة في القراءة O(1))
        List<String> names = new ArrayList<>();
        names.add("أحمد");
        names.add("سارة");
        names.add("أحمد"); // تكرار مسموح

        // LinkedList: قائمة مرتبطة دوالياً (سريعة في الإضافة والتحذيف في المنتصف O(1))
        LinkedList<Integer> numbers = new LinkedList<>();
        numbers.addFirst(10);
        numbers.addLast(20);

        System.out.println("الاسم الأول: " + names.get(0)); // إخراج: أحمد
    }
}
ArrayList: الأفضل للقرارات المتكررة والبحث.
LinkedList: الأفضل للإضافة والحذف المستمر.
Vector: خيار آمن برمجياً (Thread-Safe) ولكنه أبطأ.

3. واجهة المجموعات الفريدة (Set Interface)

تُستخدم لتخزين عناصر فريدة فقط (لا تسمح بالتكرار)، وتضم 3 تطبيقات رئيسية: 

import java.util.*;

public class SetDemo {
    public static void main(String[] args) {
        // 1. HashSet: أسرع أداء O(1) ولكن الترتيب عشوائي
        Set<String> hashSet = new HashSet<>();
        hashSet.add("تفاح"); hashSet.add("موز"); hashSet.add("تفاح"); // سيتم العزل تلقائياً

        // 2. LinkedHashSet: يحافظ على ترتيب الإدخال
        Set<String> linkedSet = new LinkedHashSet<>();
        linkedSet.add("الأول"); linkedSet.add("الثاني");

        // 3. TreeSet: يرتب العناصر أبجدياً أو رقمياً تلقائياً O(log n)
        Set<Integer> treeSet = new TreeSet<>();
        treeSet.addAll(Arrays.asList(45, 12, 89, 3));
        System.out.println(treeSet); // المخرجات المرتبة: [3, 12, 45, 89]
    }
}

4. خرائط المفاتيح والقيم (Map Interface)

تُخزن البيانات على شكل أزواج (Key → Value). المفاتيح فريدة دائماً، بينما القيم يمكن تكرارها: 

import java.util.*;

public class MapDemo {
    public static void main(String[] args) {
        // HashMap: بحث سريع جداً بقيمة المفتاح Hash Code
        Map<String, Double> salaries = new HashMap<>();
        salaries.put("أحمد", 15000.0);
        salaries.put("منى", 18500.0);
        salaries.put("أحمد", 16000.0); // يوزع القيمة الجديدة فوق القديمة

        // قراءة البيانات
        System.out.println("راتب أحمد: " + salaries.get("أحمد"));

        // المرور على مفاتيح وقيم الـ Map
        for (Map.Entry<String, Double> entry : salaries.entrySet()) {
            System.out.println(entry.getKey() + " : " + entry.getValue());
        }
    }
}

5. الطوابور والصفوف (Queue & Deque Interface)

تُستخدم لإدارة البيانات التي تُعالج بترتيب معين مثل FIFO (First In First Out) أو حسب الأولوية: 

import java.util.*;

public class QueueDemo {
    public static void main(String[] args) {
        // 1. PriorityQueue: معالجة العناصر حسب الأولوية الصغرى أو الكبرى
        Queue<Integer> pQueue = new PriorityQueue<>();
        pQueue.offer(30); pQueue.offer(10); pQueue.offer(20);
        System.out.println(pQueue.poll()); // يخرج العنصر الأصغر: 10

        // 2. ArrayDeque: طابور مزدوج الطرفين (Double-Ended Queue) يتيح العمل كـ Stack أو Queue
        Deque<String> deque = new ArrayDeque<>();
        deque.addFirst("العنصر 1");
        deque.addLast("العنصر 2");
        deque.removeFirst();
    }
}

6. طرق التكرار والمرور (Iteration Mechanisms)

تتيح Java طرقاً متعددة للتنقل داخل المجموعات بأمان وتجنب استثناء ConcurrentModificationException: 

import java.util.*;

public class IterationDemo {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("Java", "Python", "C++");

        // 1. استخدام Iterator الآمن للتعديل والحذف أثناء التكرار
        Iterator<String> it = list.iterator();
        while (it.hasNext()) {
            String lang = it.next();
            if (lang.equals("C++")) it.remove();
        }

        // 2. Java 8+ Stream API للفلترة والعمليات المتقدمة
        list.stream()
            .filter(s -> s.startsWith("J"))
            .forEach(System.out::println);
    }
}

7. فرز الكائنات المخصصة (Comparable vs Comparator)

لفرز كائنات معقدة (Custom Objects)، نستخدم إما الترتيب الطبيعي عبر Comparable أو الترتيب المخصص عبر Comparator: 

import java.util.*;

class Product {
    String name; double price;
    public Product(String name, double price) { this.name = name; this.price = price; }
}

public class SortDemo {
    public static void main(String[] args) {
        List<Product> products = Arrays.asList(
            new Product("Laptop", 1200.0), new Product("Mouse", 25.0)
        );

        // الفرز حسب السعر باستخدام Comparator و Lambda
        products.sort(Comparator.comparingDouble(p -> p.price));
    }
}

8. البرمجة المعممة والرموز البديلة (Generics & Wildcards)

تضمن Generics الأمان البرمجي أثناء وقت التجميع (Compile-time Type Safety) وتمنع أخطاء التنوع: 

import java.util.*;

public class GenericsDemo {
    // Upper Bounded Wildcard: القراءة فقط لأي نوع يرث من Number
    public static double sumOfList(List<? extends Number> list) {
        double sum = 0.0;
        for (Number n : list) sum += n.doubleValue();
        return sum;
    }

    public static void main(String[] args) {
        List<Integer> ints = Arrays.asList(1, 2, 3);
        System.out.println("المجموع: " + sumOfList(ints));
    }
}

9. جدول التعقيد الزمني (Big-O) والنصائح الإرشادية
هيكل البيانات البحث (Search) الإضافة (Insertion) الحذف (Deletion)
ArrayList O(1) عبر Index O(1) في النهاية O(n) shift
LinkedList O(n) مرور كامل O(1) عند المؤشر O(1) عند المؤشر
HashSet / HashMap O(1) متوسط O(1) متوسط O(1) متوسط
TreeSet / TreeMap O(log n) O(log n) O(log n)
